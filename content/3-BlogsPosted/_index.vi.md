Tại đây là phần liệt kê và giới thiệu các blog mình đã đăng trên [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj).

###  [Blog 1 - Xây dựng AIOps cho ứng dụng trên Amazon Bedrock](3.1-Blog1/)
Blog này giới thiệu cách xây dựng kiến trúc AIOps cho workload Amazon Bedrock bằng CloudWatch Alarms, SNS, Lambda, Service Quotas, AWS Support API và email notification.

###  [Blog 2 - Xử lý đối tượng Amazon S3 ở quy mô lớn với AWS Step Functions Distributed Map](3.2-Blog2/)
Blog này giới thiệu cách Step Functions Distributed Map xử lý object trong S3 theo prefix, đọc nội dung file với LOAD_AND_FLATTEN và mở rộng các workflow dữ liệu như phân tích log.

###  [Blog 3 - Amazon S3 Annotations](3.3-Blog3/)
Blog này giới thiệu Amazon S3 annotations, tính năng giúp gắn ngữ cảnh có thể truy vấn trực tiếp vào object trong S3 để phục vụ analytics, data lake, media platform và AI workflow.
