During my internship at **Amazon Web Services Vietnam Company Limited** from **May 5, 2026** to **July 30, 2026**, I had the opportunity to study, practice, and apply AWS Cloud knowledge to a practical deployment project. The internship focused on learning AWS services, designing a deployment architecture for the **VibeMatch** application, building a workshop, writing technical blog posts, joining a community event, and completing the internship report.

Through this process, I significantly improved my self-learning ability, cloud deployment mindset, technical documentation skills, and hands-on experience with AWS Console, AWS CLI, Docker, EC2, DocumentDB, API Gateway, Amplify, Route 53, ACM, and WAF. I also practiced writing structured documentation, presenting workshop content, and summarizing weekly progress.

In terms of working attitude, I tried to complete tasks on schedule, proactively investigated issues, and received feedback from my supervisor to improve the quality of the final deliverables. Although there are still areas that need further improvement, the internship helped me better understand professional working requirements and how to apply academic knowledge to real-world problems.

## Strengths

* Able to self-learn and explore new technologies, especially AWS services used for web application deployment.
* Able to combine multiple cloud services into a practical deployment architecture.
* Willing to improve deliverables, revise documentation, and refine content based on feedback.
* Completed the main deliverables, including the worklog, proposal, blog posts, event section, workshop, and internship report.

## Areas for Improvement

* Improve time management so that work progress is more consistent across each week.
* Improve technical communication, especially presenting problems in a concise and structured way.
* Continue strengthening troubleshooting skills when cloud systems encounter network, security, or service configuration issues.
* Practice more with automation, infrastructure as code, and monitoring to support more production-ready deployments.

## Conclusion

Overall, I assess that I completed the main requirements of the internship well. The internship helped me gain practical AWS Cloud experience, understand the process of deploying a web application on cloud infrastructure, and develop a more responsible working attitude. The remaining limitations will guide my continued improvement in future study and work.
